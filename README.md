## The fortune

> Your agent will fix the bug at 3 AM — by deleting the feature that caused it.

## How it works

`main.ts` writes exactly that one line (77 characters) to `/output/entry.txt`,
deterministically — the same bytes on every run. No network, no dependencies,
Node standard library only.

## Run

```sh
node main.ts
```
